# Shortly — Accorciatore di URL sicuro

Progetto di apprendimento: costruire, distribuire e mettere in sicurezza
un'applicazione su AWS.

## Obiettivo
Un servizio che trasforma un URL lungo in un link corto, distribuito nel cloud
e messo in sicurezza strato dopo strato (HTTPS, secret, privilegio minimo,
rate limiting, log).

## Stack
- Backend: (da confermare — Python/FastAPI o Java/Spring Boot)
- Cloud: AWS
- Sicurezza: documentata in /docs/security-log.md

## Diario
- Settimana 1: creazione del repository e dell'account AWS sicuro.
